# Panel de señales · cuenta demo

Proyecto estudiantil. Página web que lee el precio de la pestaña compartida (OCR con Tesseract.js), calcula una señal ARRIBA/ABAJO con EMA, momentum y RSI, y evalúa si acertó tras la duración de la operación.

**No opera ni hace clic**: solo sugiere y mide. Compara la tasa de acierto con el punto de equilibrio (54,05 % con pago del 85 %) y calcula un p-valor.

Uso: abre la página en Chrome → *Compartir la pestaña* → marca la columna de precios → *Iniciar*.
